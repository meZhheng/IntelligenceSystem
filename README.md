# IntelligenceSystem

这是一个由前后端组成的智能分析系统。

## 模块组成

### WebServer
后端服务，负责：
- 接口提供与业务编排
- 数据存取与任务调度
- 检测、分析与汇总结果输出
- 系统配置与环境变量管理

### WebUI
前端应用，负责：
- 用户登录与页面导航
- 数据集、模型与任务管理界面
- 分析结果展示与可视化大屏
- 博客、公众号、账号等业务页面

## 主要功能

- 账号与权限相关功能
- 数据集管理与导入
- 模型分析与推理展示
- 舆情/风险内容检测与统计展示
- 任务监控与结果查看
- 大屏可视化展示

## 目录说明

- `WebServer/`：后端代码
- `WebUI/`：前端代码

## 说明

项目中部分功能依赖运行时环境配置，请在部署时按实际环境补齐相关配置项。
